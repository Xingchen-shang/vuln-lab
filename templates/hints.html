💡 破解提示

这里是所有靶场的破解思路和 payload。为了让你独立思考，靶场页面本身不提供任何提示，卡住了再来这里看。

① SQL 注入

目标：绕过登录，以 admin 身份登录。

  1. 用户名输入 admin' --，密码随意。
  2. 登录成功即拿到 flag。
  3. 原理：-- 是 SQL 注释符，把后面的密码条件注释掉了。

② 存储型 XSS

目标：在留言板注入脚本，读取 Cookie 里的 flag。

  1. 留言内容填入下面的 payload 并提交： 
    <script>alert(document.cookie)</script>
  2. 刷新留言板，脚本执行，弹窗里就能看到 Cookie。
  3. flag 在未开启 HttpOnly 的 xss_flag Cookie 中。

③ CSRF

目标：利用已登录的 alice，把钱转给 hacker。

  1. 登录 alice（受害者）。
  2. 保持登录，打开「攻击页面」，隐藏表单会自动把钱转给 hacker。
  3. 退出，登录 hacker，余额 > 0 即拿到 flag。

④ 暴力破解

目标：爆破 victim 的弱口令。

  1. 用户名已知为 victim。
  2. 用 Burp 拦截登录请求 → Send to Intruder → 只标记 password 的值。
  3. Payloads 用 Simple list，加载弱口令字典（123456、password、admin…）。
  4. Start attack，长度明显不同的那条即正确密码，登录后拿 flag。

⑤ IDOR 越权

目标：以 alice 身份越权查看 admin 的资料。

  1. 以 alice 登录，点「查看我的资料」，请求是 /idor/profile?id=1。
  2. 用 Burp 拦截（或 Send to Repeater），把 id=1 改成 id=2。
  3. 发送后即可看到 admin（id=2）的私密资料，里面就是 flag。
